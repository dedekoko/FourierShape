# مركز واحد — سلسلة دوائر واحدة من مركز الشكل

يرسم محيط أي شكل من صورة بسلسلة دوائر دوّارة واحدة (Fourier epicycles) تنطلق من **مركز الشكل**، وطرفها هو القلم. كلما زاد عدد الدوائر اقترب الرسم من الأصل.

للأسلوب الثاني، سلسلتان خارج الشكل: [../2-centers](../2-centers/README.md).

## المحتويات

| الملف | ما هو |
|---|---|
| `fourier_shape.py` | البرنامج: يأخذ صورة ويُخرج فيديو MP4 يرسم الشكل على مراحل |
| `locales/ar.json` | نصوص البرنامج الظاهرة |
| `fourier_live.html` | الواجهة التفاعلية: رسم حيّ، عدد الدوائر والنقاط، رفع صورة، جدول المعاملات |
| `images/` | صور الاختبار (قط وخريطة إيطاليا من Wikimedia Commons، ملك عام) |
| `*.mp4` | فيديوهات ناتجة: كمان، قط، إيطاليا |
| `cat_100_circles.csv` | معاملات أكبر 100 دائرة لشكل القط |

## التشغيل

```bash
pip install opencv-python numpy
```

من داخل المجلد `1-center`:

```bash
python fourier_shape.py images/cat.png --out cat.mp4 --show
```

الخيارات: `--stages` أعداد الدوائر في كل مرحلة، `--points` عدد نقاط المحيط، `--show` نافذة حيّة، `--explain N` طباعة حساب أوّل `N` دائرة خطوة بخطوة.

شرح الطريقة كاملًا، وأين كل خطوة في الكود: [docs/شرح-طريقة-العمل.md](docs/شرح-طريقة-العمل.md).

الواجهة التفاعلية تُفتح مباشرة في المتصفح، أو عبر الخادم المحلي في `.claude/launch.json`.

## الطريقة

1. يُستخرج محيط أكبر شكل في الصورة (قناة الشفافية إن وُجدت، وإلا عتبة Otsu).
2. تُوزَّع على المحيط `N` نقطة متساوية التباعد، فتثبت سرعة المرور.
3. يُحسب تحويل فورييه المتقطّع للنقاط بوصفها أعدادًا مركّبة:

```
c_k = (1/N) · Σ z_j · e^(−2πi·k·j/N)      z_j = x_j + i·y_j
```

4. كل معامل دائرة (نصف قطرها `|c_k|`، وسرعتها `k`)، وتُرتَّب من الأكبر إلى الأصغر، ويُرسم الشكل بأوّل `n` منها:

```
z(t) = c_0 + Σ c_k · e^(i·k·t)
```

أقصى عدد للدوائر هو عدد النقاط ناقص واحد.
