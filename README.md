# FourierShape — رسم الأشكال بدوائر فورييه

دوائر دوّارة ترسم محيط أي شكل. في المشروع أسلوبان، لكلٍّ منهما مجلده وشرحه:

| المجلد | الأسلوب | أهمّ ما فيه |
|---|---|---|
| [`1-center/`](1-center/README.md) | **مركز واحد:** سلسلة دوائر واحدة تنطلق من مركز الشكل، وطرفها القلم | برنامج بايثون يحوّل صورة إلى فيديو، وواجهة تفاعلية، وشرح طريقة العمل |
| [`2-centers/`](2-centers/README.md) | **مركزان:** سلسلتان خارج الشكل، فوقه وبجانبه، وخطّان متقطّعان يلتقيان عند القلم | صفحة تفاعلية على مثلث ومربّع ونجمة، وشرح الأسلوب |

الصفحات تُفتح مباشرة في المتصفح، أو عبر الخادم المحلي في `.claude/launch.json`.
